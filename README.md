# Nuke Discord Rich Presence

Shows what you're doing in Nuke on Discord: script name, node count, current frame,
edition/version, elapsed time, and editing / rendering / idle state. No dependencies;
talks to Discord's local IPC pipe. Works on Nuke 11+ (Py2/Py3, PySide2/6), all platforms.

## Setup
1. Run `install.ps1` (or copy `nuke_discord_rpc/` into `~/.nuke` and add
   `import nuke_discord_rpc; nuke_discord_rpc.start()` to `menu.py`).
2. Restart Nuke. Done: the Application ID is built in.

Developer side (one-time, already done): the Discord application's Art Assets need the keys
`nuke`, `editing`, `rendering`, `idle` (generated by `make_assets.py` into `assets/`).
To use your own application, set it via **Discord RPC > Set Application ID...** or `NUKE_DISCORD_CLIENT_ID`.

Settings are saved to `~/.nuke/discord_rpc.json`. The menu toggles script name (privacy),
node count, frame, and on/off. Guarded by `nuke.GUI`, so it does nothing in `nuke -t` / render nodes.
